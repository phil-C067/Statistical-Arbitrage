# Statistical Arbitrage with Pairs Trading

## Overview

This project investigates a statistical arbitrage strategy based on pairs trading using Python.

The aim is to identify two assets with a stable long-run relationship, construct a mean-reverting spread between them, generate trading signals based on deviations from the spread's historical behaviour, and evaluate the strategy using historical market data.

The project focuses on both the mathematical foundations of the strategy and its practical performance when backtested.

## Objectives

* Investigate the relationship between two financial assets
* Test for cointegration
* Construct a statistical spread
* Develop a mean-reversion trading strategy
* Generate trading signals using spread z-scores
* Backtest the strategy on historical data
* Incorporate transaction costs and slippage
* Evaluate risk and performance
* Test the strategy on out-of-sample data
* Analyse the robustness and limitations of the strategy

## Methods

The project will use:

* Python
* NumPy
* Pandas
* Matplotlib
* Statsmodels
* Historical market data

Key quantitative concepts include:

* Correlation
* Linear regression
* Cointegration
* Mean reversion
* Z-scores
* Statistical hypothesis testing
* Backtesting
* Sharpe ratio
* Maximum drawdown
* Transaction costs
